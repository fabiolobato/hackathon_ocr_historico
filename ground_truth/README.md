These text files are extracted from the user-supplied Word transcription, one file per source JPEG. The original DOCX remains unchanged. Each `.txt` has exactly the source image's stem. The document's section headings identify the image number, so no inferred page splitting is required.

Extraction preserves all supplied wording, punctuation, capitalization, abbreviations and spelling. Only whitespace is normalized. Bibliographic/image section headings, empty paragraphs and the underscore-only separator are omitted. The supplied transcription generally excludes the printed watermark, top-margin rubric signatures and page numbers; predictions of those elements can count as insertions. Editorial readings, expanded abbreviations and apparent transcription errors can also affect WER. No text is silently corrected to agree with an OCR result.

`review.json` records provenance, source paragraph indices, hashes and `supplied_unverified` status. `comparison_review.md` records a visual comparison against every source image and suggested corrections. After checking the complete transcription, correct the `.txt` and set that page's `status` to `reviewed`. Do not mark reviewed merely because OCR agrees with the reference. Scores against unreviewed pages remain labeled provisional. No complete independent AI transcription had been saved when the supplied GT arrived; the comparison is against the visible source handwriting, not against an invented prior output.

Transcriptions, the source document and review metadata are local dataset artifacts ignored by Git. Include this directory and `Imagens/` when uploading to Colab. Run artifacts record the reference hash and review metadata used. The extraction utility refuses to overwrite a reference if it has been edited.
