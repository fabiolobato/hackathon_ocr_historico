# Fotos da demonstração ao vivo

As fotos das folhas escritas à caneta, copiadas do celular, ficam nesta pasta: é daqui que `demo_ao_vivo.ipynb` (ou `python -m ocr_pipeline.demo --vigiar`) lê a foto mais recente e a passa pelos dois OCRs do projeto. As fotos ficam só no computador: o `.gitignore` deixa de fora tudo nesta pasta menos este README. O que cada OCR recebeu, os textos e os cartões vão para `outputs/demo/`, fora do git. Ver `docs/DEMO.md`.
